Dragon Quest IX Modern v3: installing works again, the HD pack downloads by itself, and the game now runs on Linux and the Steam Deck.

**Fixed since v2.1**
- **Installing works again**: from RecompLauncher or `Install Dragon Quest IX.bat`, the install could stop with "python: command not found" because the tools and Python did not install. They install reliably again, and the townspeople in 3D are made again (they were skipped when Python's numpy was missing). If the install still fails, RecompLauncher now shows why on its last line (for example Python, gcc or make missing), and the full log is in `build/build.log`.
- Modern menus with HD text: the message after using an item shows whole in its own window, with no cut copy of it in the windows around the menu. It was cut inside the item's menu window, or not shown at all after choosing who to use the item on.
- **Safer saves**: if writing the save fails (crash, power cut, full disk), `dqix.sav` is no longer left empty or cut short; the previous save stays whole.

**What's new since v2.1**
- **HD pack** (Windows): the game downloads it by itself in the background, with HD textures (FatalPixels, by twittman) and remade movies. A bar at the bottom left shows "HD pack: N%" then "HD pack ready". The textures show as soon as it is done, the movies from the next start. To turn it off: Graphics > Download the HD pack (textures and movies).
- **Use several items at once** (European version): after Use on an item you hold more than once and choosing who, A opens "How many do you want to use?" (Left/Right: 1 more or less, L/R: 10, Up: all, Down: 1), then a Yes / No question. The items are used one after another, with their messages. Not in battles.
- Patty's Invite a friend: the lists show in the modern windows, see-through like her dialogue.
- **What's new**: after an update, the game shows once what changed, in the game's language. Help > What's new shows it again.
- **Linux and Steam Deck**: `BUILD.sh` builds the game on Linux and on the Steam Deck, also from RecompLauncher, and each release now has a Linux zip. Guide: `docs/LINUX-STEAMDECK.md`.
- New Discord invite in the README, and the game's page in RecompLauncher shows properly.

**How to install**: download *Source code (zip)* below, unzip it and double-click `Install Dragon Quest IX.bat`, then choose your own ROM (USA or European). Or install it from RecompLauncher. On Linux or the Steam Deck, see `docs/LINUX-STEAMDECK.md`. **Already installed?** The game offers the update when it starts (or Help > Check for updates): your saves and settings are kept.

**Not included, on purpose**: no ROM, no game executable and no data from any game. Everything is built on your PC from the ROMs you own. The HD pack only holds remade pictures and movies, downloaded by the game.

**Playing with friends**: everyone needs the same version, so all of you update to v3.
